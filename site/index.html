See local AI token usage at a glance.

Token Bar totals token usage from local Codex, OpenCode, and Claude Code history files and shows it in the menu bar. File reads only. No accounts. No trackers. Costs are estimates only, never a bill.

Three local sources, one total

  • Codex input 1,240,000 local session files
  • OpenCode input 860,500 local database, plus opt-in remote snapshot
  • Claude Code input 412,300 local project files

Figures above are layout samples, not your usage. The app reads your on-disk history read-only: Codex session files, the OpenCode database, and Claude Code project files. Multi-machine OpenCode merge is an offline snapshot copy or an opt-in pull over your own SSH setup. Missing sources degrade to an empty total plus a sanitized warning, never a crash and never a raw path.

Compact first, details on demand

The 400pt popover opens compact: hero total, estimated cost, source chips (All, Codex, OpenCode, Claude), range chips (Today, 24H, 7D, 30D, Best, All), a composition ring, a source bar, and a 14-day mini trend. Details expands to metric cards, top-5 models, the full trend, and notices. Cached tokens are a subset of input; reasoning is a subset of output; neither is added on top of the total.

Costs are estimates

Every dollar figure is labelled an estimate from a static rate table, not a bill. Subscription use is not an API invoice. One strictly opt-in refresh fetches public model pricing metadata; without it the app stays fully offline on the built-in table.

Local-first boundary

  • Usage data, prompts, message bodies, paths, and credentials never leave the machine.
  • No accounts, no provider APIs, no cookies, no analytics on this page and none in the app.
  • Only two network uses exist in the app, both strictly opt-in and disabled by default: the public pricing refresh and the remote snapshot pull over your own SSH setup.

Unsigned build: how to open

Releases are unsigned and not notarized. macOS Gatekeeper shows a warning on first launch. That is expected: right-click Open the app once, then launch normally. DMG install: open the dmg, drag TokenBar.app onto Applications, open. ZIP install: unzip, drag TokenBar.app to Applications, open.
